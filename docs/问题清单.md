## 1. `UserController.class.newInstance()` 和 `UserController.getClass().newInstance()` 一样吗？

**结论：不一样。** 前者合法；后者若 `UserController` 是类名，编译失败。

**出现位置：** `minispring-web/src/test/java/PhraseTest1.java`（给 `com.minispring2.web.core.RequestMapping.object` 赋控制器实例时）。

### 对照

| 写法 | 前提 | 结果 |
|------|------|------|
| `UserController.class.newInstance()` | 类名 | 一定是 `new UserController()` |
| `UserController.getClass().newInstance()` | `UserController` 当类名 | **编译失败**：`getClass()` 是实例方法，不能用类名调用 |
| `controller.getClass().newInstance()` | `controller` 是实例 | 按**运行时类型**再 new，可能是子类 |

### 原因

- `.class`：写在**类型名**后面的类字面量，得到 `Class<UserController>`。
- `getClass()`：`Object` 的**实例方法**，必须先有对象：`某个对象.getClass()`。

### 正确写法

```java
requestMapping.object = UserController.class.newInstance();
// 更推荐（newInstance 已过时）
requestMapping.object = UserController.class.getDeclaredConstructor().newInstance();
```

### 相关易错写法

| 写法 | 结果 |
|------|------|
| `UserController.class` | `Class<UserController>`，对 |
| `UserController.class.newInstance()` | `new UserController()`，对 |
| `UserController.class.getClass()` | 得到 `Class.class`（`java.lang.Class` 这个类），错 |
| `UserController.class.getClass().newInstance()` | 试图 `new Class()`，运行失败 |
| `UserController.class.class` | **编译错误**：`.class` 不能跟在表达式后面 |

记法：要 `Class` 对象时，**有实例用 `getClass()`，只有类型名用 `.class`。**
